

# Chat Application

## Tecnologias Utilizadas:

### Frontend
- **React** (Vite)
- **Tailwind CSS**
- **Zustand**

### Backend
- **Node.js** e **Express**
- **Socket.IO**
- **MongoDB**

## Funcionalidades:
- **Autenticação de Usuários**: Tela de login e cadastro com validação.
- **Mensagens em Tempo Real**: Troca instantânea de mensagens usando Socket.IO.
- **Interface Amigável**: Design com foco na experiência do usuário.
- **Gerenciamento de Estado**: Estados globais otimizados com Zustand.

## Como Executar o Projeto

### Requisitos
- Node.js instalado
- MongoDB configurado

### Passo a Passo
1. Clone o repositório
2. Entre em cada pasta (frontend/backend) e rode ```npm Install```
3. Entre em cada pasta (frontend/backend) e rode ```npm run dev```
